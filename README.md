# UniDB — Database Engine (Rust)

A university database-engine project implemented in Rust. The source is organized into parser, execution engine, storage, and model modules.

## Project structure
- `src/parser/` — query parsing
- `src/engine/` — command representation and execution
- `src/storage/` — collection/storage implementations
- `src/models/` — data models

## Run
Requires the Rust toolchain (Cargo). From this directory:

```bash
cargo run
```

## Language
Rust
